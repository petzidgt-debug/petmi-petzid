    Configuración y reglas

    Sorteo automático

    Junta a quienes esperan a quién enviarle con quienes esperan libro, dando prioridad a los gustos. Quien no tenga pareja compatible sigue esperando al siguiente sorteo. Se puede correr cuantas veces quieras.

    Registrar libros

    Escribe el código de la etiqueta (BP-…). "Recibido en PetMi" y "Entregado" usan el código de quien envía; "Ángel Lector entregado", el de quien recibe.

    Quién espera su libro

    Ordenado por días de espera. Escríbele a quien envía para recordarle, o activa el Ángel Lector para que PetMi envíe un libro de respaldo.

    Ruta de entrega

    Libros en PetMi y Ángeles Lectores pendientes, con dirección. Cada vez que se abre queda registrado.

    Participantes

    Estantería

    Todos los libros ofrecidos. Retira los que no cumplan las reglas (solo si todavía no están apartados para un envío).

    Lista de espera de BookPal

    Personas que se apuntaron desde la home de Tribbi para que les avisen cuando BookPal abra.
